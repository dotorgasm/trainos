# TRAIN/OS

Diario di allenamento personale, mobile-first.

- Serie, carichi, ripetizioni, attrezzatura e note.
- Storico, sessioni saltate e report copiabile.
- Salvataggio sul dispositivo, backup e importazione JSON.

I dati restano nel browser. Nessun invio automatico a ChatGPT.

Per GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
Apri il sito in Safari e aggiungilo alla schermata Home. Per NFC usa lo stesso URL.

La pagina include `noindex` per i motori che lo rispettano. Questo non rende privati il sito o il repository e non nasconde il profilo GitHub o i commit.

La sola scheda Full Body è dimostrativa, non personalizzata. Nei programmi JSON ogni esercizio può includere `"equipment": "2 manubri + panca piana"`. Le spunte della bozza esistente vengono conservate negli aggiornamenti.
